Funcionamento

Defina os horários disponíveis.

Intervalo de almoço

Os horários dentro desse período serão bloqueados.

☕
Exemplo: das 12:00 às 13:30. O sistema também impede dois agendamentos no mesmo horário.

Como os horários são calculados

A agenda usa o horário de abertura, fechamento e o intervalo entre horários definidos aqui. Horários que caem no almoço ou já possuem atendimento são marcados como indisponíveis. A duração do serviço também é considerada para evitar sobreposição.

Backup e dados

Exporte ou restaure seus registros.

↗

Exporte um arquivo JSON com clientes, pets, agenda, serviços, despesas e configurações. Quando conectado, os dados também são sincronizados com a nuvem.

Para apagar os dados locais deste navegador, use com cuidado.

Modelos de WhatsApp

Campos disponíveis: {cliente}, {pet}, {data}, {hora}, {servico}, {loja}. O WhatsApp abre com a mensagem pronta para revisar e enviar.

Dados sincronizados com Supabase quando você está conectado. Mantenha backups periódicos; sincronização na nuvem não substitui backup. Se houver falha de conexão, confira o status de sincronização antes de fechar a página.
